# あとで知ったこと：プロンプト一式

LINE風メッセージゲーム。プレイヤーは主人公として自由に返信を書き、相手のキャラは全員AIが演じる。
各シナリオには「主人公だけが知らない真相」があり、会話の中の違和感（伏線）に気づけるかが勝負。
章が終わるごとに評価が出て、最後に真相と「あとで読み返すと」の答え合わせがある。

ジャンルは何でもいい。プリセットは毎回AIが新しく作る。

## 遊び方（3つのモード）

| モード | ユーザーが決めること | 真相 |
|---|---|---|
| おまかせ | 何も決めない。AIが作ったカードから選ぶ | 知らない |
| 大枠指定 | ジャンル・相手・雰囲気・あらすじなど好きなだけ | 知らない（AIが裏で決める） |
| フル自作 | 真相まで全部 | 知ってる（友達に遊ばせる用） |

大枠指定でも真相はAIが決めるので、自分で考えた話でもネタバレなしで遊べる。

## 処理の流れ

```
[コード] seeds.json からサイコロを振る（4〜6セット）
   │      大枠指定なら、ユーザーの入力で一部を上書き
   ▼
[1_preset.md]   企画カードを作る ── hidden はサーバーに保存、画面には出さない
   │
   ▼  ユーザーがカードを1枚選ぶ（フル自作はここから入る）
[2_scenario.md] シナリオ全体を作る ── 全部サーバーに保存
   │
   ▼
[3_play.md]     プレイ。プレイヤーの発言ごとに呼ぶ
   │            chapter_end: true が返ったら ↓
[4_chapter_eval.md] 章末評価（演じてるAIとは別の呼び出し）
   │            最終章が終わるまで 3 ↔ 4 をくり返す
   ▼
[5_ending.md]   答え合わせと総合評価
   │
   ▼
[コード] 真相の要約を履歴に追加して、次の 1_preset の avoid に渡す
```

## 守ること

- ランダム性はコードで作る。AIに「毎回違うのを考えて」と頼むだけだと同じ話ばかりになる。
- `truth` `hidden` `clues` `endings` `hindsight` はクライアントに送らない。
- シナリオJSONはプレイ中ずっと毎回プロンプトに入れる。入れないと設定がブレる。
- 評価は演じてるAIにやらせない。自分の話に甘くなる。
- 推奨 temperature：1_preset は高め（1.0前後）、2_scenario は中くらい、3_play は中くらい、4・5 は低め。
